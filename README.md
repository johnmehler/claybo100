# Math Museum: Game Station

A premium math and logic game collection platform built with Svelte 5, featuring a high-fidelity glassmorphic interface and smooth micro-interactions.

## Features

- **Game Selection Hub:** A central menu to discover and launch different gaming experiences.
- **Sliding Tiles:** Classical 15-puzzle with modern physics and shimmer effects.
- **Pegboard:** English peg solitaire simulator with perfect win detection.
- **Tower of Hanoi:** Strategic disc-stacking puzzle with customizable difficulty.
- **ShotSim:** Physics-based basketball trajectory simulator.
- **Premium UX:** Seamless transitions (fade/fly), glassmorphism, and responsive design.

## Tech Stack

- **Framework:** Svelte 5 (Runes)
- **Build Tool:** Vite
- **Styling:** Vanilla CSS
- **Typography:** Outfit (Google Fonts)

## Games

### 1. Sliding Tiles
Arrange the tiles in numerical order (1-15) by sliding them into the empty space.

### 2. Pegboard
The classic English peg solitaire game. Jump over pegs to remove them until only one remains.

### 3. Tower of Hanoi
Move a stack of discs from one rod to another. Challenge yourself with 3 to 8 discs.

### 4. ShotSim
Master the physics of projectile motion by adjusting angle and power to hit the target hoop.
